
# 🫁 lungcancer-prediction.ai

lungcancer-prediction.ai è un progetto che utilizza un modello di Machine Learning per prevedere la probabilità di sviluppare il cancro ai polmoni. Il modello è stato allenato su un dataset reale di pazienti, preso da Kaggle, e offre una semplice interfaccia grafica realizzata con Tkinter per facilitare l'uso del modello.

## 📌 Introduzione

lungcancer-prediction.ai nasce dall'esigenza di utilizzare tecnologie di Machine Learning per predire la possibilità di sviluppare il cancro ai polmoni. Utilizzando un dataset con dati reali dei pazienti, il modello analizza vari fattori di rischio e fornisce una previsione sulla probabilità di sviluppare questa malattia. L'interfaccia grafica sviluppata con Tkinter permette di interagire facilmente con il modello.

## 🧑‍💻 Funzionalità

- **Previsioni sulla Probabilità di Cancro ai Polmoni**: Modello di Machine Learning per prevedere se una persona è a rischio di sviluppare il cancro ai polmoni.
- **Interfaccia Grafica**: Un'interfaccia utente semplice e intuitiva realizzata con Tkinter.
- **Visualizzazione dei Risultati**: Mostra i risultati in modo chiaro, con la probabilità di diagnosi di cancro ai polmoni.
- **Facile da usare**: Semplici input per inserire i dati del paziente e ottenere una previsione.

## 📊 Dataset

Il dataset utilizzato per allenare il modello proviene da Kaggle, ed è composto da dati reali di pazienti. Puoi trovare il dataset e maggiori dettagli qui:

```bash
lungcancer-prediction.ai/dataset
```

## 🛠️ Installazione

Assicurati di avere installati:

- **Python** 3.8+ per il backend e la GUI
- **Tkinter** per la creazione dell'interfaccia grafica

### Passaggi per eseguire il progetto:

1. Clona il repository:
```bash
git clone https://github.com/tuo_username/lungcancer-prediction.ai.git
cd lungcancer-prediction.ai
```

2. Crea un ambiente virtuale e installa le dipendenze:
```bash
python -m venv env
source env/bin/activate  # Su Windows: env\Scripts\activate
pip install -r requirements.txt
```

3. Per eseguire il modello, avvia la GUI con Tkinter:
```bash
python main.py
```
